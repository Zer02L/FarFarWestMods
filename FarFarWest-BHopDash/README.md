# BHopDash Enhanced (Far Far West)

Мод для **Far Far West** (UE4SS), обеспечивающий полноценный и отзывчивый Bunny Hop (банни-хоп) и Dash-Hop.

## Возможности

1. **Auto-BHop (авто-прыжок при приземлении)**:
   - Зажмите `SpaceBar` (пробел) — персонаж автоматически совершает идеальный прыжок в момент касания земли без пропуска кадров и спама клавиши.
2. **Auto-Dash (авто-дэш при приземлении)**:
   - Зажмите `LeftShift` (или настроенную клавишу) — при касании земли мгновенно срабатывает дэш.
3. **Auto-Jump After Dash (дэш-хоп связка)**:
   - Сразу после рывка при приземлении автоматически активируется прыжок (`AUTO_JUMP_AFTER_DASH=true`). Горизонтальный импульс скорости дэша переносится в полёт, позволяя непрерывно лететь с максимальной скоростью по карте.
4. **Сброс кулдауна дэша**:
   - `RESET_DASH_COOLDOWN=true` позволяет делать дэш-хопы непрерывно без искусственных задержек.
5. **Двойная детекция приземления**:
   - Нативные хуки движка (`OnLanded` и `K2_OnMovementModeChanged`) срабатывают моментально (0 ms latency).
   - Фоновый поллинг каждые 10 ms гарантирует срабатывание даже при сетевых лагах или падении FPS.
6. **Надёжная привязка к игроку**:
   - Работает через `UEHelpers.GetPlayerController()` и `AcknowledgedPawn`.
   - Автоматически восстанавливает управление после смерти, возрождения или смены карты (`ClientRestart`).

---

## Управление по умолчанию

* **Пробел (`SpaceBar`)**: зажмите для непрерывного классического банни-хопа (прыжки сразу при касании земли).
* **Левый Shift (`LeftShift`)**: зажмите для скоростного Dash-Hop (дэш на приземлении + мгновенный выпрыг вперед с сохранением скорости).

---

## Настройка (`config.txt`)

Файл конфигурации находится в `ue4ss/Mods/BHopDash/config.txt`:

```ini
ENABLED=true
DASH_KEY=LeftShift
BHOP_KEY=SpaceBar
AUTO_BHOP_ENABLED=true
AUTO_DASH_ENABLED=true
AUTO_JUMP_AFTER_DASH=true
RESET_DASH_COOLDOWN=true
AUTO_JUMP_DELAY_MS=15
POLL_MS=10
DEBUG=false
```

Поддерживаются любые клавиши: `SpaceBar`, `LeftShift`, `LeftControl`, `LeftAlt`, `ThumbMouseButton` (Mouse4), `ThumbMouseButton2` (Mouse5) и др.
